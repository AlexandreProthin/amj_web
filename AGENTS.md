# Project guidance

Start with the root of the project knowledge base: [agent_wiki/index.md](agent_wiki/index.md).

Treat `agent_wiki/` as the maintained project memory. Before making or planning
project changes, read its maintenance protocol and record durable requirements,
decisions, and implementation plans there. Keep the wiki validated and its
visualization current when it is changed.

The starting draft materials are in `draft_data/`.
